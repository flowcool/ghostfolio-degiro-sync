# Design

## Context

IBKR v3.0.0 commit `403b4ccf13dcce076c2dc4c08633905c96c1a898` (tag object `f181c957`); DEGIRO `7751e02f90c73b0e44e67f052c715226af436aa8`. Tasks map requirements. Historical soak instructions are obsolete.

## Goals / Non-Goals

Adopt the implemented common foundation, including its core. Retain broker-specific accounting and stronger DEGIRO safeguards. No shared library or historical rewrite.

## Decisions

| Modules | Responsibility; source reference |
| --- | --- |
| `models`, `config` | Validated settings/results; IBKR equivalents |
| `vault`, `degiro` | Existing DEGIRO credentials/reads; IBKR input separation |
| `accounting`, `identity` | DEGIRO conversion; IBKR grammar and dual-reader rules |
| `ghostfolio` | Bounded transport/core adapter; IBKR `ghostfolio.py` |
| `journal`, `sync` | Durable DEGIRO execution; IBKR orchestration separation |
| `diagnostics`, `notify` | Exact comparison, plain reports, worker; IBKR equivalents |
| `app`, `__main__` | Commands; IBKR equivalents |

Keep calculations as functions. Use secret-free frozen records. Validate external data before typing it. Preserve evidence and journals. Separate reads, pure indexing, selection and accepted-result recording, following IBKR's interfaces. Adapt broker ownership and holdings; exclude Flex logic.

Extend provenance with ordered source files, hashes and selected units. Flatten the explicit dependency closure into generated `ghostfolio_core.py`, preserving selected unit bytes. Include `Config`, annotation imports and `log_lab_evidence`; exclude unrelated IBKR imports. The core adapter alone binds transport/log state and restores it. No sibling edits or concurrency.

Adopt Python 3.14 and the isolated worker. Pin tools. Exclude generated bytes from style rewriting.

Use `DEGIRO#v1#<account>:<KIND>:<id>` for the first versioned generation. Preserve legacy readers and exact source IDs. Do not convert stored comments. Retain original symbol identity through an explicit returned-profile mapping; no amount-only UUID matching.

Reports use original numeric evidence without extra reads. Dividend activity quantity does not prove security quantity. Keep EUR/USD/JPY. Exclude IBKR-only rounding causes.

## Risks / Trade-offs

Core signatures, global binding, partial imports and diagnostic dependencies can drift: prove each adapter contract against the pinned source. DEGIRO keeps cash blocked after uncertain imports, despite IBKR's independent-cash rule.

## Migration Plan

Approve first. Update `AGENTS.md`, Python conventions, `CONTRIBUTING.md`, OpenSpec context and the existing style guard together. Preserve credential isolation, additive writes, account refusal, journal ownership and recovery. Extract, adopt the current core, then align contracts. Reuse existing backlog owners after approval. Extend the existing lab in infra; stop only owned instances. Revert source commits atomically; preserve journals and new rows. After v1 rows exist, rollback requires a qualified dual reader. Stable publication and real operations retain explicit GO gates.
