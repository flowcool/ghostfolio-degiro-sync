# Design

## Context

IBKR v3.0.0 `403b4ccf13dcce076c2dc4c08633905c96c1a898` (object `f181c957`); DEGIRO `7751e02f90c73b0e44e67f052c715226af436aa8`. Tasks map requirements. No soak gate.

## Goals / Non-Goals

Adopt the common core and DEGIRO identity conversion together. Retain broker accounting and stronger safeguards. No shared library or financial correction.

## Decisions

| Modules | Responsibility; source reference |
| --- | --- |
| `models`, `config` | Frozen records/settings; IBKR equivalents |
| `vault`, `degiro` | Existing credentials/reads; IBKR separation |
| `accounting`, `identity` | DEGIRO accounting; common identity grammar |
| `ghostfolio` | Private transport/core adapter; IBKR `ghostfolio.py` |
| `journal`, `sync` | Functions over typed records; durable execution |
| `diagnostics`, `notify`, `app`, `__main__` | IBKR report/worker/command separation |
| `degiro_identity_maintenance.py` | DEGIRO adaptation of IBKR `identity_migration.py` and `cleanup_recovery.py` |

Validate external data before typing it. Preserve evidence and journals. Inject clocks into pure indexing/selection. Record only confirmed results. Keep broker ownership and exact holdings outside the byte core.

The core spec lists source-qualified units, SHA256 hashes, import order and collision rules. Preserve selected bytes. Install root `ghostfolio_core.py` as a module. Keep authentication in the private adapter. Suppress core logs; emit evidence once from the adapter.

First prove Python 3.14 dependency compatibility. Install the package and preserve the old command during extraction. Move canonical cash rules into the package; use resource lookup. Keep transitional imports tested. Remove the old command last. Exclude generated bytes from rewriting.

Use `DEGIRO#v1#<account>:<KIND>:<id>` and retain legacy readers. Inventory all history; convert proven comments through an explicit maintenance command. Bind exact evidence and unchanged selection in a keyed YAML manifest. Preserve uncertain rows. Qualify MANUAL/zero-valued updates and UUID associations.

Reports reuse exact evidence without extra reads. Activity quantity does not prove dividend security quantity. Keep EUR/USD/JPY and proven DEGIRO causes. Configure only connector logging.

## Risks / Trade-offs

API updates carry financial fields: qualify preservation before conversion. Journal each request; uncertain writes stop. Partial imports keep cash blocked. A qualified candidate forced to simulation provides safe halt, not restoration of old data.

## Migration Plan

Apply approved policy surfaces together. Keep `v` image tags. Complete offline tasks, archive, replay main, publish RC, qualify both labs, then promote or execute the authorized cutover. Stop writers, preview, convert, verify, preview sync, resume. No reader-only release or elapsed-time gate. Reverse only unchanged journal-owned comments; retain new rows. After v1 exists, never restore an unqualified old binary. Publication and real operations retain explicit GO gates.
