# Domain documentation

Before changing financial semantics, read docs/source-contract.md and the topical
contract (fees, interest/compensation, synchronization, prospective cutover or
recovery). CORE_PROVENANCE.md owns the immutable broker-independent projection.
Before architecture, domain naming or recovery changes, read docs/architecture.md,
GLOSSARY.md and the relevant decisions in docs/adr/. Use their vocabulary and
report conflicts with the topical contracts before changing behavior.
